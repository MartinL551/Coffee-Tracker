# ☕ Coffee Tracker

A small personal project built with **Next.js** and deployed on **Vercel**, created to explore modern frontend workflows, server-side rendering concepts, and simple state management in a production-like setup.

🔗 **Live demo:** https://coffee-tracker-ashy.vercel.app/  
📦 **Repository:** https://github.com/MartinL551/Coffee-Tracker

---

## Overview

Coffee Tracker is a lightweight web application that allows users to log and track their coffee consumption throughout the day. The project focuses on simplicity and clarity, serving as a practical exercise in building, deploying, and maintaining a modern web application using a meta-framework.

The goal of this project was not to build a complex product, but to gain hands-on experience with:
- a modern React-based framework
- file-based routing
- component-driven UI
- deployment workflows using Vercel

---

## Tech Stack

- **Next.js** – React-based framework with built-in routing and SSR support  
- **JavaScript** – application logic and UI behaviour  
- **CSS** – basic styling  
- **Vercel** – hosting and deployment

---

## Features

- Log coffee entries during the day  
- Simple, clean user interface  
- Responsive layout  
- Deployed live using a modern CI/CD-style workflow

---

## Motivation

This project was built as part of my ongoing effort to strengthen my understanding of modern frontend frameworks and deployment pipelines. While the functionality is intentionally simple, it reflects a complete development cycle — from local development to a publicly deployed application.

It also serves as a stepping stone toward working with comparable frameworks such as **Nuxt**, where similar concepts apply across ecosystems.
